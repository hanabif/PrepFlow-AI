# PrepFlow - Quick Start Guide

## What is PrepFlow?

PrepFlow is a production-ready AI interview preparation SaaS platform built with Next.js 16, TypeScript, Supabase, and OpenAI.

- 🎯 **AI-Powered:** Generate realistic interview questions and get AI evaluations
- 📊 **Analytics:** Track your progress with beautiful dashboards and charts
- 🔒 **Secure:** Built on Supabase with row-level security
- 🚀 **Production-Ready:** Full backend, authentication, and database

## Getting Started (Local Development)

### 1. Prerequisites


## Making it Real (Full Setup)

Follow these steps to enable real backend functionality:

### Step 1: Supabase Setup (5 minutes)

1. Go to https://supabase.com
2. Click "Create New Project"
3. Choose region and password
4. Wait for project to initialize
5. Go to Settings → API → Copy credentials:
   - `NEXT_PUBLIC_SUPABASE_URL`
   - `NEXT_PUBLIC_SUPABASE_ANON_KEY`
   - `SUPABASE_SERVICE_ROLE_KEY`

6. Create `.env.local` file:
```bash
cp .env.local.example .env.local
```

7. Paste Supabase credentials into `.env.local`

8. Go to Supabase SQL Editor
9. Run migration from `db/migrations/schema.sql`
10. Verify 5 tables created successfully

### Step 2: OpenAI Setup (2 minutes)

1. Go to https://platform.openai.com/api-keys
2. Create new API key
3. Add to `.env.local`:
```
OPENAI_API_KEY=sk-...
```

### Step 3: Test Integration

```bash
# Restart dev server to load new env vars
pnpm dev

# Sign up with real account
# Go to /signup
# Create new account (now persists to Supabase)

# Start interview
# Questions now generated by OpenAI
# Answers evaluated by AI
# Analytics persist to database
```

### Step 4: Deploy to Vercel

```bash
# Push to GitHub
git push origin main

# Connect to Vercel
vercel link

# Add environment variables in Vercel dashboard:
# Settings → Environment Variables
# Add all from .env.local

# Deploy
vercel deploy --prod
```

## Common Questions

### Q: Can I use this without integrations?
**A:** Yes! Everything works with mock data out of the box. Perfect for demos and portfolios.

### Q: How much does it cost?
**A:** 
- Supabase: Free tier up to 500K requests/month
- OpenAI: ~$0.10-0.15 per interview
- Vercel: Free tier for projects under 100K function invocations

### Q: Is it production-ready?
**A:** The frontend and backend architecture are production-ready. Just add your own credentials.

### Q: Can I customize it?
**A:** Absolutely! All code is yours to modify. Tailwind CSS makes styling easy.

### Q: How do I add more questions?
**A:** Edit `lib/mock-data.ts` or integrate real OpenAI (recommended).

## Troubleshooting

### Build Fails
```bash
# Clear build cache and reinstall
rm -rf .next node_modules
pnpm install
pnpm build
```

### Environment Variables Not Loading
```bash
# Make sure .env.local exists and is in correct format
cp .env.local.example .env.local
# Restart dev server: pnpm dev
```

### Database Queries Fail
```bash
# Verify in Supabase dashboard:
# 1. Tables created (SQL Editor)
# 2. RLS policies enabled
# 3. Service role key is correct
# 4. User authenticated before queries
```

### OpenAI Errors
```bash
# Check API key is valid at platform.openai.com/api-keys
# Verify .env.local has OPENAI_API_KEY=sk-...
# Watch for rate limits (free tier has limits)
```
